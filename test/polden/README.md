# Проверка обработки файлов Polden

Из корня репозитория (Qt — та же версия, что использована для OBS):

```powershell
cmake -S test/polden -B build_polden_transfer -DCMAKE_PREFIX_PATH="$PWD/.deps/obs-deps-qt6-2026-07-15-x64"
cmake --build build_polden_transfer --config Release
$env:Path = "$PWD/.deps/obs-deps-qt6-2026-07-15-x64/bin;" + $env:Path
ctest --test-dir build_polden_transfer -C Release --output-on-failure
```

Тест вызывает те же функции, что рабочий пайплайн: проверяет содержимое и SHA-256, повторную доставку, запрет перезаписи другого содержимого, имена с кириллицей, TXT и старые CSV, отмену в процессе копирования, удаление временного файла и повтор после отмены. Временные данные создаются в текущем каталоге и удаляются через QTemporaryDir.

`polden-slow-converter` — отдельный тестовый процесс для ручной проверки кнопки отмены конвертации. Он создаёт временный файл по последнему аргументу и ждёт 120 секунд. Использовать только как FFmpeg в изолированной тестовой конфигурации; в рабочую сборку он не включается. Проверить: Cancel processing завершает именно этот процесс, удаляет `.polden-part-*`, сохраняет исходник, помечает активное и ожидающие задания `cancelled: true`. После перезапуска они не запускаются сами. Отмена окончательная; Resume отсутствует. Retry доступен только для ошибок.

Проверка настоящей записи и конвертации: `node scripts/test-polden-markers.mjs <изолированный runtime>`. Профиль должен иметь ручное разделение записи и доступный OBS WebSocket; проект — уровень 2 с локальной тестовой папкой вместо рабочего LucidLink. Скрипт проверяет восемь цветов 1–8 в TXT, паузу, split, исходные имена видео и маркеров, одинаковые копии, сохранение сочетаний и отсутствие внешнего InfoWriter. Рабочую конфигурацию пользователя для теста не использовать.

Тест `polden-default-preset` проверяет установку Full HD-пресета в пустую конфигурацию, одну игровую аудиодорожку, отсутствие личных путей и сохранение существующих профилей и сцен при повторном запуске.

Тест `polden-redesign` проверяет преобразования шаблонов имени и папки (включая старые токены и кириллицу), безопасность подстановки имён, правила папок и состав удаления дубля: все сегменты одной игры, сохранность предыдущего дубля и другой игры, исключение чужих конфликтующих и общих файлов. `polden-file-transfer` также проверяет монотонный прогресс байтов и список доставленных видео/сайдкаров.
