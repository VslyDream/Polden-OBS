# Polden OBS 0.1.0 для macOS

Mac-сборки добавляются в существующий релиз `polden-v0.1.0`, рядом с Windows ZIP:

- `Polden-OBS-0.1.0-macOS-arm64.zip` — Apple Silicon.
- `Polden-OBS-0.1.0-macOS-x86_64.zip` — Intel.
- Для каждого архива публикуется отдельный `.zip.sha256`.

Внутри ZIP находится `Polden OBS.app`. После распаковки приложение можно перенести в «Программы». Цель сборки — macOS 13.0 и новее. Имя, версия 0.1.0, идентификатор `com.vslydream.polden-obs` и иконка устанавливаются при упаковке. База OBS остаётся 32.2.2.

Приложение подписано локальной ad-hoc подписью, без Apple Developer ID и нотарификации. При первом запуске скачанного приложения macOS может заблокировать открытие. Для приложения из этого репозитория используйте разрешение конкретного приложения в «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть», как описано в [инструкции Apple](https://support.apple.com/en-ie/102445).

Помощник обновлений версии 0.1.0 поддерживает только Windows. Новую Mac-версию следует скачивать из GitHub Releases. Настройки OBS/Polden находятся в пользовательском каталоге Application Support, вне `.app`. Источник `Game Capture`, на который рассчитан автоматический выбор игрового окна Polden, относится к Windows; на Mac захват настраивается через стандартные источники OBS для macOS. Работа записи и захвата экрана на конкретном Mac требует пользовательских разрешений macOS и отдельной проверки.

## Сборка

Workflow `.github/workflows/polden-macos.yaml` запускается вручную на ветке `polden-obs`. Используются отдельные macOS-машины GitHub для arm64 и Intel, Xcode и CMake. Исходники приложения берутся из неизменённого опубликованного тега `polden-v0.1.0`, включая подмодули. Упаковщик берётся из ветки, с которой запущен workflow; его ревизия видна в запуске Actions.

Настройки сборки фиксируют базу OBS 32.2.2 и отключают канал Sparkle исходного OBS. Кеш компилятора Xcode отключён из-за ошибки CAS в образе runner; предупреждение Clang о временных Qt JSON-итераторах не превращается в ошибку сборки. Остальные проверки компилятора сохраняются. Виртуальная камера собирается штатными средствами OBS; системное camera extension требует подписания Apple Developer, поэтому полноценная работа виртуальной камеры на Mac этой сборкой не подтверждается.

Перед публикацией упаковщик проверяет архитектуру Mach-O, локальную подпись, вывод `--version` и отсутствие зависимостей приложения от путей Homebrew или рабочего каталога runner. Он сохраняет ресурсы и символические ссылки `.app` с помощью `ditto`. Отдельный шаг сверяет SHA-256 и добавляет оба ZIP и контрольные суммы в существующий релиз. Уже опубликованные Windows-файлы этим workflow не заменяются.

Это проверка сборки, упаковки и запуска команды версии на машинах GitHub. Запись игры, захват экрана, разрешения macOS и доставка на LucidLink должны проверяться на рабочем Mac.
