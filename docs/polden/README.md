# Разработка Polden OBS

Форк OBS Studio 32.2.2 для Windows: [VslyDream/Polden-OBS](https://github.com/VslyDream/Polden-OBS). Исходный тег: `obsproject/obs-studio`, `32.2.2`; основная ветка: `polden-obs`. Базовый код и лицензия GPL-2.0-or-later сохранены.

Текущая версия Polden OBS — **0.3.0**, база OBS — **32.2.2**. В версии 0.3.0 реализован утверждённый вариант A: меню игр и ⚙, три режима **After recording**, компактные чипы маркеров, карточка дубля с прогрессом, окончательная отмена и **Delete last take…**. Настройки **Files** содержат шаблоны имени и папки, имя оператора и свёрнутый **Advanced**; **Markers** — видимость восьми чипов и горячие клавиши с проверкой конфликтов. Локальные файлы удаляемого дубля отправляются в Корзину, копии LucidLink удаляются насовсем после подтверждения. Исходное имя записи сохраняется при конвертации и доставке, TXT маркеров лежат рядом. Автоматического импорта в Premiere нет.

Точка запуска актуальной Windows-сборки: `D:\3_Proga\Polden-OBS\latest\bin\64bit\obs64.exe`. `latest` — ссылка на последний успешно собранный Release-каталог; сборочный скрипт обновляет её и ярлык «Polden OBS» в меню «Пуск». Поэтому поиск Windows и прямой запуск файла ведут к одной версии. Папку `latest` не удалять и не копировать отдельно от репозитория.

Правило локальных обновлений: после успешной сборки и проверки сразу выкатывать её на этот компьютер через `scripts/Publish-PoldenBuild.ps1`, сохраняя текущие настройки и плагины. Если OBS запущен, сначала подготовить новую сборку в отдельном каталоге и спросить в чате: **«Новая сборка готова. Закройте Polden OBS — после закрытия я сразу обновлю его на компьютере. Сообщите, когда закроете.»** После ответа проверить процесс и завершить установку. Подробные инструкции для агента — [AGENTS.md](../../AGENTS.md).

Настройка записи, подготовка MP4 и доставка на LucidLink описаны в [README](../../README.md).

## Внесение изменений

- Команды выполняются из корня репозитория. Зависимости и сборка описаны в [инструкции Windows](build-windows.md); историческая сборка macOS 0.1.0 — в [отдельной инструкции](build-macos.md).
- Следуйте [правилам стиля кода OBS](../development/code-style.md) и конфигурациям форматирования в корне. Проверяйте изменённые C/C++ файлы через `clang-format --dry-run --Werror <файлы>`, а пробелы в diff — через `git diff --check`.
- Проверки выбирайте по изменённой части: CTest из `test/polden` для логики Polden, `scripts/test-polden-markers.mjs` для записи и маркеров, `python scripts/test-local-publish.py` для локальной установки, `python scripts/test-windows-updater.py` для обновления из ZIP. Условия интеграционной проверки маркеров описаны в [отчёте о тестировании](ui-redesign-testing.md).
- В коммите указывайте причину изменения и выполненные проверки. Для изменений только документации достаточно проверить ссылки и `git diff --check`.
- После успешной сборки и необходимых проверок обновляйте локальный Polden по [AGENTS.md](../../AGENTS.md); перед заменой файлов работающий OBS должен быть закрыт пользователем.

## База OBS Studio

Polden использует [OBS Studio](https://obsproject.com), исходный тег — [32.2.2](https://github.com/obsproject/obs-studio/tree/32.2.2). [Справочник API OBS](https://obsproject.com/docs) и [инструкции OBS](https://github.com/obsproject/obs-studio/wiki) полезны при работе с базовым кодом.

[Текст лицензии](../../COPYING), [список авторов OBS](../../AUTHORS) и исходный [GPL Cooperation Commitment](../upstream/COMMITMENT) сохранены. Лицензии компонентов находятся рядом с их исходниками в `deps/` и `plugins/`.

По вопросам Polden используйте контакт из [основного README](../../README.md). Правила участия и каналы поддержки OBS Project относятся к исходному проекту; для отправки изменений в OBS следуйте [их инструкции](https://github.com/obsproject/obs-studio/blob/32.2.2/CONTRIBUTING.md).
