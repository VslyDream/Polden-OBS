# Стандартный пресет Polden Gameplay

Проверен 02.11.2026: `L:\~OBS_Profile\1_Track_(only_game)`. Состав утверждён пользователем 02.11.2026 с изменением разрешения на **Full HD 1920×1080**. Описание исходного пресета ниже сохранено для сравнения.

## Что находится в исходном пресете

Пять файлов: коллекция сцен `Gameplay.json`, профиль `Gameplay/basic.ini`, параметры записи `recordEncoder.json`, параметры стрима `streamEncoder.json` и сервис `service.json`. Сервисные ключи не нужны для анализа и в сборку не переносятся.

| Параметр | Фактическое значение |
| --- | --- |
| Режим вывода | Advanced |
| Холст / выход | 2560 × 1440, без масштабирования |
| Частота | 60 кадров/с, целочисленная |
| Цвет | P010, 10 бит, Rec.709, ограниченный диапазон; SDR white 300, HDR peak 1000 |
| Контейнер записи | Fragmented MP4 (`fragmented_mp4`) |
| Кодировщик записи | NVIDIA NVENC HEVC (`obs_nvenc_hevc_tex`) |
| Качество записи | CQP 22, Main10, ключевой кадр 2 с, multipass fullres |
| Preset NVENC записи | Не задан явно: используется значение по умолчанию кодировщика. `p7` есть только в **streamEncoder.json** |
| Аудио | Stereo, 48 кГц, AAC |
| Дорожки записи | Только № 1 «Game», 320 кбит/с |
| Дополнительные дорожки | «Mic» и «Discord» названы в профиле, но в запись не включены |
| Разделение записи / replay buffer / auto remux | Выключены |
| Старт / остановка | Оба действия на Alt+F1 |
| Реальная папка записи | `E:/Recordings/Gameplay`, из `[AdvOut] RecFilePath` |
| Реальный шаблон имени | `Artur_%Y-%m-%d_%H-%M-%S`, из `[Output] FilenameFormatting` |

Коллекция **Gameplay** содержит одну сцену «Сцена» и один источник «Захват игры»:

- Захват конкретного окна `TS_CasinoRoyal.exe` (The House Always Wins), приоритет сопоставления 1.
- Звук приложения включён; источник не заглушён, громкость ≈ 79,9% (−1,95 дБ).
- Курсор включён, захват сторонних оверлеев выключен, anti-cheat compatibility hook выключен, hook rate 1.
- Источник видим, позиция 0,0, масштаб 1:1, без кропа и фильтров. Переход Fade, 300 мс.
- Отдельных источников микрофона, Discord и звука рабочего стола в файле нет. Скрипты, субтитры и автопереключение сцен выключены; маркеров нет.

В `basic.ini` остались неактивные параметры SimpleOutput и секция `[AdvOutput]` (другое имя секции, чем используемое OBS `[AdvOut]`), включая `D:/Screen/Dead`, имя `Dead_Artur_2026-01-18-20-00-05` и старый пользовательский путь `C:\Users\Aust917\Videos`. Они не определяют текущую Advanced-запись и не должны попадать в чистый пресет. CookieId, геометрия окна статистики и стриминговая конфигурация тоже не нужны.

## Утверждённый состав стандартной сборки

1. Профиль **Polden Gameplay**: Full HD 1920×1080, 60 FPS, HEVC Main10/CQP 22, fragmented MP4, AAC 48 кГц/320 кбит/с, одна игровая дорожка, Alt+F1. Аппаратный профиль требует доступного NVIDIA NVENC HEVC с поддержкой 10 бит; запасной кодировщик надо выбирать отдельно, без молчаливой смены качества.
2. Коллекция **Polden Gameplay**: одна сцена с захватом игры и её звука. Убрана привязка к `TS_CasinoRoyal.exe`; начальный режим — захват полноэкранной игры, конкретное окно задаётся в проекте Polden. Источник вписывается в рамку 1920×1080 с сохранением пропорций, чтобы игра с большим разрешением не обрезалась. Глобальные микрофон и Desktop Audio явно выключены, чтобы первый запуск OBS не добавил лишний звук.
3. Папка записи — стандартная папка видео текущего пользователя. Шаблон имени — как в текущем рабочем профиле Polden: `%CCYY-%MM-%DD/Vasiliy_%CCYY-%MM-%DD-%hh-%mm-%ss` (папка даты и имя с датой/временем); имя `Artur` и пути чужого компьютера не переносить. Имя можно изменить через **Polden settings → General → Recording / MP4 filename**.
4. Маркеры — встроенные Polden, TXT `H:MM:SS,1–8`, с настройкой сочетаний и кнопок в **Markers**. Внешний InfoWriter не нужен.
5. Профиль и сцены автоматически выбираются только в новой конфигурации. При обновлении сохраняются существующие профиль, сцены, проекты, шорткаты и пути пользователя.

Файлы пресета входят в `data/obs-studio/polden/defaults/` общей Windows-сборки. На первом запуске `OBSApp::AppInit` устанавливает и выбирает профиль и коллекцию, если нет выбранных профиля/сцен, отметки завершённого первого запуска и существующих файлов в каталогах профилей/сцен. Путь записи подставляется штатно для текущего пользователя; мастер автоконфигурации не заменяет готовый пресет. Повторные запуски и обновления не меняют существующую конфигурацию. Сервис потоковой трансляции, внешние плагины и личные настройки в пресет не входят.
