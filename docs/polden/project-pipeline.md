# Проекты и пайплайн Polden 0.2.2

**Проект = игра.** Для проекта сохраняются ID, название, корень на LucidLink, папка видео, источник OBS «Захват игры» и выбранное окно. Уровень автоматизации задаётся для каждой игры. Имя записывающего, шаблон папки и путь FFmpeg общие. Имя видео берётся из исходной записи OBS. Настройки хранятся в `config/obs-studio/polden.json`, задания — в `polden-jobs.json`; личные файлы исключены из Git.

## Интерфейс

- Выбор игры, добавление и редактирование проекта. При выборе применяется сохранённое окно захвата.
- Уровни: **0 · OBS only**, **1 · Convert MP4**, **2 · LucidLink**.
- **Open files folder**: папка скопированного файла последней записи выбранной игры; если копирование ещё не завершено — папка готового MP4, затем исходной записи. Проверяется наличие файла. Если записи ещё нет, открывается существующая папка видео проекта уровня 2, иначе папка записи активного профиля OBS. Недоступный путь отображается как ошибка без создания папок.
- **Cancel processing** отменяет FFmpeg, активное копирование и все незавершённые задания, включая другие проекты и ожидающую очередь. Исходники и готовые файлы сохраняются; временные файлы удаляются при завершении отмены. Отмена сохраняется между запусками. **Resume cancelled job** возобновляет последнее отменённое задание выбранного проекта; после него можно возобновить предыдущее. Неудачные шаги доступны через **Retry last failed step**.
- **Polden settings… → Markers**: восемь цветов, глобальные горячие клавиши и галочки **Button on panel**. По умолчанию кнопки маркеров скрыты; выбранные цвета добавляются на панель и ставят маркер одним кликом. Отдельный плагин и источник не нужны. [Подробнее](markers.md).
- Номер версии и маленький значок баг-репорта в нижнем правом углу: [@Vsly_Dream](https://t.me/Vsly_Dream).

В форме проекта указываются название, корень игры, папка видео, источник и окно захвата. «Detect paths» подставляет `02_Assets/01_VIDEO` относительно корня игры. В настройках — имя записывающего, шаблон папки, FFmpeg, текущий шаблон имени записи/MP4 активного профиля OBS и пример результата.

## Обработка записи

Игра, уровень и настройки фиксируются при старте записи. Путь каждого завершённого сегмента берётся из OBS. Этапы: `recorded -> converted -> copied`; ошибки сохраняются для повтора и не удаляют исходник.

FFmpeg выполняет `-c copy -movflags +faststart -f mp4` во временный файл. Имя и время в исходном названии сохраняются, в том числе у каждого сегмента; меняется только расширение. Локальный MP4 хранится в `Polden Converted/<projectId>/<jobId>/`, чтобы одноимённые записи не смешивались. CSV/TXT копируются рядом с MP4 уже на уровне 1 и затем на LucidLink. Копирование проходит через временный файл с проверкой SHA-256. Если на LucidLink уже есть файл с тем же именем и содержимым, он считается доставленным; при другом содержимом задание останавливается с ошибкой. Название не меняется, существующий файл не перезаписывается.

Шаблоны папки: `{root}`, `{footage}`, `{user}`, `{date}` (`YYYY-MM-DD`), `{timestamp}` (`YYYY-MM-DD-HH-mm-ss`). По умолчанию папка — `{footage}/{date}`. Поле **Recording / MP4 filename** редактирует `[Output] FilenameFormatting` активного профиля OBS. Начальное значение берётся из текущего профиля; используются стандартные токены OBS (`%CCYY`, `%MM`, `%DD`, `%hh`, `%mm`, `%ss`). Расширение вводить не нужно. Во время записи поле недоступно. OK сохраняет профиль, Cancel оставляет его прежним. Конвертация сохраняет полученное исходное имя и меняет расширение. Прежний JSON `filenameTemplate` игнорируется для новых записей. Существующие задания сохраняют свои пути, чтобы не потерять уже обработанные файлы.

## Переход с 0.0.1

Существующие проекты и задания читаются. Прежний уровень 3 становится уровнем 2. Ошибки бывшего шага импорта после успешного копирования снимаются при чтении. Поля Premiere игнорируются и не сохраняются при следующей записи настроек или очереди. Импорт, кнопки Premiere, сервер связи, автоустановка и ресурсы расширения удалены. Ранее установленное расширение Adobe автоматически не удаляется.
