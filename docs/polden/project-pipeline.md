# Проекты и пайплайн Polden 0.2.2

**Проект = игра.** Для проекта сохраняются ID, название, корень на LucidLink, папка видео, источник OBS «Захват игры» и выбранное окно. Уровень автоматизации задаётся для каждой игры. Имя записывающего, шаблон папки и путь FFmpeg общие. Имя видео берётся из исходной записи OBS. Настройки хранятся в `config/obs-studio/polden.json`, задания — в `polden-jobs.json`; личные файлы исключены из Git.

## Интерфейс (редизайн A)

- Меню игр содержит режим каждой игры, **Add game…**, **Edit…**, **Open video folder**. ⚙ открывает настройки Polden.
- **After recording**: **Keep file**, **Convert MP4**, **MP4 → Lucid**. Игра и режим фиксируются при старте записи; изменения во время записи применяются к следующему дублю.
- Карточка выбранной игры показывает запись с таймером и последним маркером, обработку с процентом/бегущей полосой, результат, отмену или ошибку. Во время записи предыдущая обработка занимает отдельную компактную строку. **Open folder** открывает существующую папку доставленного MP4, локального MP4 либо исходника, с переходом к папке проекта/профиля при отсутствии дублей.
- **Cancel** отменяет активный FFmpeg, копирование и незавершённую очередь. Отмена окончательная, сохраняется между запусками; **Retry** доступен только для ошибки последнего дубля. Источники и уже готовые файлы сохраняются; временные файлы удаляются.
- **Delete last take…** перечисляет исходники, локальные MP4, копии и TXT/CSV всех сегментов одного дубля выбранной игры. По умолчанию подтверждение отменяется. После подтверждения останавливается только этот дубль; локальные файлы идут в Корзину, доставленные копии удаляются насовсем. Чужие конфликтующие файлы доставки и пути, на которые ссылаются другие задания, исключаются. При ошибке удаления история сохраняется для повторной попытки. При успехе показывается предыдущий дубль.
- **Delete game…** удаляет только запись об игре после подтверждения, сохраняя файлы и задания, включая снимок игры текущей записи.
- **Markers**: чипы видимости восьми цветов, шорткаты в две колонки и × для очистки. Повтор сочетания у разных цветов подсвечивает оба поля и блокирует Save. Дополнительные сочетания остаются доступными на общей странице OBS Hotkeys и сохраняются при редактировании первого сочетания.
- В подвале — версия, баг-репорт и плашка **Update to X.Y.Z**, когда доступна проверенная новая версия.

Диалог игры начинается с папки LucidLink, затем показывает имя, папку видео, читаемое окно «заголовок / exe» и источник Game Capture. Выбор папки пересчитывает имя и папку видео, ↺ повторяет пересчёт. Параметры **Advanced**: `videoSubfolder` (по умолчанию `02_Assets/01_VIDEO`), `gameNameTemplate` (`{folder}`), FFmpeg. Правила не изменяют существующие проекты без явного пересчёта.

## Обработка записи

Игра, уровень и настройки фиксируются при старте записи. Путь каждого завершённого сегмента берётся из OBS. Этапы: `recorded -> converted -> copied`; ошибки сохраняются для повтора и не удаляют исходник.

FFmpeg выполняет `-c copy -movflags +faststart -f mp4` во временный файл. Имя и время в исходном названии сохраняются, в том числе у каждого сегмента; меняется только расширение. Локальный MP4 хранится в `Polden Converted/<projectId>/<jobId>/`, чтобы одноимённые записи не смешивались. CSV/TXT копируются рядом с MP4 уже на уровне 1 и затем на LucidLink. Копирование проходит через временный файл с проверкой SHA-256. Если на LucidLink уже есть файл с тем же именем и содержимым, он считается доставленным; при другом содержимом задание останавливается с ошибкой. Название не меняется, существующий файл не перезаписывается.

Шаблоны папки: `{video folder}` / `{footage}`, `{game folder}` / `{root}`, `{name}` / `{user}`, `{date}` (`YYYY-MM-DD`), `{timestamp}`. **Files → File name** принимает `{name}`, `{game}`, `{date}`, `{time}` и стандартные токены OBS. Кнопки Insert вставляют токен в позицию курсора. Шаблон активного профиля сохраняется в `[Polden] FilenameTemplate`; применённое значение — в `[Output] FilenameFormatting`. При смене игры и перед записью имя и игра подставляются текстом, дата/время переводятся в токены OBS. Переход из старого профиля сохраняет буквальные части имени; переопределение через OBS Output имеет приоритет. Во время записи имя файла недоступно. Cancel сохраняет настройки без изменений. Пример показывает полный путь в нативном формате Windows и соседний TXT.

Задания содержат `takeId` для объединения сегментов, длительность дубля и сегмента, число маркеров и `deliveredFiles` для частично завершённой доставки. Старые задания группируются по игре и `recordedTimestamp`. Прогресс FFmpeg читается через `-progress pipe:1`, копирование сообщает байты из `copyVerified`; до получения измерений отображается бегущая полоса. 100% копирования байтов ещё требует проверки SHA-256 и доставки маркеров: до завершения этапа карточка показывает не более 99%.

## Переход с 0.0.1

Существующие проекты и задания читаются. Прежний уровень 3 становится уровнем 2. Ошибки бывшего шага импорта после успешного копирования снимаются при чтении. Поля Premiere игнорируются и не сохраняются при следующей записи настроек или очереди. Импорт, кнопки Premiere, сервер связи, автоустановка и ресурсы расширения удалены. Ранее установленное расширение Adobe автоматически не удаляется.
