# Проекты и пайплайн Polden

Статус: первая реализация в `frontend/widgets/PoldenPanel.cpp` и `PoldenPipeline.cpp` (24.09.2026). Сборка и проверка в работе. Связь с Premiere требует отдельной панели `premiere/polden-bridge`.

## Основная сущность

**Проект = игра.** Для проекта сохраняются устойчивый ID, название, корень на LucidLink, папка видео, путь к `Footage.prproj`, источник OBS `Захват игры` и выбранное в нём окно. Уровень автоматизации хранится отдельно для каждой игры. Имя записывающего и шаблоны путей/имён общие; папка видео и Premiere проект задаются для каждой игры. Личные пути и список проектов хранятся в `config/obs-studio/polden.json`, задания — в `polden-jobs.json` портативной версии; эти файлы исключены из Git.

## Панель

1. Выпадающий список проектов, добавление и редактирование проекта. В форме: название игры, корень на LucidLink, автоматически найденные с возможностью правки папка назначения и Production/Footage, текущее окно источника `Захват игры`. При выборе проекта окно источника переключается на сохранённое.
2. Шкала автоматизации с четырьмя накопительными уровнями:

   | Уровень | Действие после записи |
   | --- | --- |
   | 0 | Обычная работа OBS без действий Polden |
   | 1 | Конвертация в обычный MP4 без перекодирования |
   | 2 | Уровень 1 и доставка в папку игры на LucidLink |
   | 3 | Уровень 2 и импорт в Premiere |

3. Отдельные действия Premiere: импортировать последнюю запись выбранной игры в `Footage`; добавить её в конец активной секвенции открытой Production этой игры. Рядом — состояние текущего/последнего задания и ошибки. Выбор игры и уровня фиксируется при старте записи; последующее переключение списка не меняет начатое задание.
4. Кнопка настроек Polden: имя записывающего, шаблоны имени, папки и bin, путь к FFmpeg, ключ связи с Premiere и галочка очереди при недоступном Premiere. В форме показан пример итогового пути. Если очередь выключена, задание сохраняет ошибку и доступно для ручного повтора.

## Предложенный шаблон пути

Из примера пользователя: `L:\{игра}\02_Assets\01_VIDEO\{дата_записи:YYYY-MM-DD}\{имя}_{время_начала_записи:YYYY-MM-DD-HH-mm-ss}.mp4`.

Пример Premiere: `L:\Meowgic\01_Meowgic_Production\00_Footage\01_Meowgic_Footage.prproj`; внутри проекта bin `1_VIDEO/{дата_записи:YYYY-MM-DD}`. Проверено, что эти папки и файл проекта Meowgic существуют в текущем LucidLink. Поиск `Footage` должен выдавать ошибку при неоднозначном результате, а не выбирать произвольный `.prproj`.

Дата и время фиксируются при начале записи, чтобы медленная конвертация или смена дня не меняла путь. При сегментации записи требуется сохранять номер сегмента в имени, чтобы файлы не перезаписывали друг друга. InfoWriter сейчас синхронизирует имя/путь с видео и создаёт CSV; CSV доставляется рядом с MP4. Локальные исходник и сконвертированный файл остаются на месте.

## Выполнение

Путь завершённой записи берётся из OBS после остановки. Задание хранит исходный путь, снимок ID проекта, уровень автоматизации и итоговые пути, зафиксированные при старте записи. Этапы: `recorded -> converted -> copied -> imported`; ошибки не удаляют исходник и доступны для повтора. FFmpeg выполняет `-c copy -movflags +faststart -f mp4` и пишет во временный файл. Копирование в LucidLink завершается через временный файл с SHA-256 проверкой, чтобы Premiere не увидел неполный футаж. При совпадении имени с существующим файлом добавляется числовой суффикс. Дубликаты файлов при повторах определяются по хешу, дубликаты в Premiere — по пути медиа в целевом bin.

Установленная версия Premiere — 25.6.2. Требуется отдельное расширение внутри Premiere; порядок установки и ограничения — в [premiere.md](premiere.md). Polden не правит `.prproj` напрямую. На уровне 3 автоматически выполняется импорт только в bin `1_VIDEO/{дата}`. Вставка в конец активной секвенции нужной Production выполняется отдельной кнопкой; первая версия использует видео и аудио дорожки с индексом 0. Расширение проверяет, что активный проект находится внутри папки Production нужной игры.

## Следующие итерации

- Уточнить после проверки в Premiere поведение блокировки проектов Production и вставки медиа из `Footage` в секвенцию другого проекта той же Production.
- Добавить настройку дорожек для вставки и журнал заданий в панели.
- Проверить повтор после потери подтверждения от Premiere во время вставки на таймлайн.
