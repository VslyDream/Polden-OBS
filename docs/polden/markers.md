# Встроенные маркеры Polden

Откройте **Polden settings… → Markers**. Для каждого из восьми цветов доступны шорткат и галочка **Button on panel**. Нажмите поле и нужную кнопку или сочетание, затем **OK**. Можно назначить несколько сочетаний одному цвету и очистить назначения. **Cancel** отменяет и изменение шорткатов, и выбор кнопок. Одно сочетание нельзя назначить разным цветам. По умолчанию сочетания пустые, чтобы не перехватывать управление игрой. Они также доступны на общей странице горячих клавиш OBS как `Polden marker: …`.

По умолчанию блок маркеров на панели полностью скрыт. Галочка **Button on panel** добавляет отдельную кнопку выбранного цвета; клик ставит маркер сразу, без выбора из списка. После **OK** кнопки обновляются без перезапуска, при узкой панели переносятся на следующую строку. Если все галочки сняты, блок не занимает место. Видимость кнопок не влияет на горячие клавиши. Кнопки доступны во время записи.

| Номер | Цвет Premiere | HEX |
| --- | --- | --- |
| 0 | Green / Зелёный | `#718637` |
| 1 | Red / Красный | `#D22C36` |
| 2 | Purple / Фиолетовый | `#AF8BB1` |
| 3 | Orange / Оранжевый | `#E96F24` |
| 4 | Yellow / Жёлтый | `#D0A12B` |
| 5 | White / Белый | `#FFFFFF` |
| 6 | Blue / Синий | `#482DFC` |
| 7 | Cyan / Бирюзовый | `#19F4D6` |

Номер — значение цвета, а не назначенная клавиша. Горячие клавиши работают в фоне с учётом общей настройки OBS «Hotkey Focus Behavior». В открытой форме настройки маркеры не ставятся. Во время паузы, до начала и после остановки записи маркеры не добавляются.

Маркеры работают с любым уровнем автоматизации и без выбранного проекта. После первого маркера появляется `<исходное имя>.csv` рядом с видео. Формат совместим с двухколоночным CSV InfoWriter: `HH:MM:SS.mmm,номер_цвета`, без заголовка. Например:

```csv
00:00:12.350,0
00:01:04.100,6
```

Время рассчитывается по записанным видеокадрам с учётом частоты кадров. Паузы исключаются, при разделении записи время следующего CSV начинается с нуля. Записи без маркеров не создают пустых CSV. На уровне 1 CSV копируется к MP4, на уровне 2 — также на LucidLink. Исходники сохраняются.

Сочетания и видимость кнопок хранятся в `config/obs-studio/polden-markers.json` отдельно от сцен и профиля. Схема 2 сохраняет `showButton` для каждого `Polden.Marker0`–`Polden.Marker7`; прежние назначения читаются без изменений, отсутствующий флаг означает скрытую кнопку. Старые сторонние DLL InfoWriter не загружаются, даже если остались от версии 0.1.0. Старые настройки источников и их шорткаты автоматически не переносятся: назначения задаются через **Polden settings… → Markers**. Другие форматы и события исходного плагина (стриминг, смены сцен, SRT/EDL) не входят в функцию маркеров Polden. CSV сохраняет номер цвета для последующей обработки; автоматического импорта цветных маркеров в Premiere нет.
