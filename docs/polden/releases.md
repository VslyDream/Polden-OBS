# Версии Polden OBS

## 0.2.1 — 30.10.2026

- В Polden Settings добавлены вкладки **General** и **Markers**. Цвет, горячие клавиши и видимость кнопки настраиваются в одной строке.
- По умолчанию кнопок маркеров на панели нет. Для выбранных цветов создаются отдельные кнопки, которые ставят маркер одним кликом и переносятся при сужении панели.
- Общая кнопка Add marker, список цветов и отдельная кнопка Marker shortcuts убраны. Сочетания клавиш работают независимо от видимости кнопок.
- Выбор сохраняется между запусками. OK применяет все изменения, Cancel отменяет их; прежние назначения горячих клавиш сохраняются.

## 0.2.0 — 27.10.2026

- Исходные имена записей, включая время и имена сегментов, сохраняются при конвертации и переносе на LucidLink.
- Маркеры встроены в приложение. Отдельные DLL и источник InfoWriter не нужны; старая DLL, оставшаяся в установке, не загружается и не показывается в менеджере плагинов.
- На панели — выбор цвета, **Add marker**, **Marker shortcuts…**. Для восьми цветов Premiere назначаются отдельные глобальные сочетания клавиш.
- CSV содержит время относительно текущего сегмента без пауз и номер цвета 0–7. Файл появляется после первого маркера и сохраняется рядом с исходником, локальным MP4 и копией на LucidLink.
- Настройки цветов и шорткатов хранятся в `polden-markers.json`; персональная упаковка включает их и проекты Polden без сторонней DLL InfoWriter.

## 0.1.0 — 06.10.2026

- Кнопка открытия папки с файлами выбранной игры, с переходом к готовой копии, MP4 или исходной записи.
- Удалены интеграция с Premiere, импорт, вставка на таймлайн, связанные настройки, сервер связи, автоустановка и файлы расширения.
- Небольшой значок баг-репорта в нижнем правом углу панели ведёт в [ЛС @Vsly_Dream](https://t.me/Vsly_Dream).
- Собственная версия Polden отображается в панели, заголовке, `--version`, Windows-метаданных и имени ZIP. Версия базы OBS остаётся отдельной.
- Старые проекты уровня 3 продолжают работать как уровень 2 (доставка на LucidLink).
- Тихая проверка обновлений при запуске. Если есть новая стабильная версия для Windows x64, рядом с баг-репортом появляется маленький зелёный значок обновления.
- Обновление по кнопке: загрузка с прогрессом и отменой, проверка SHA-256, штатное закрытие приложения, резервная копия, установка и перезапуск. Сохранены настройки, сцены, проекты и сторонние плагины; при ошибке замены файлов выполняется откат.
- Установка блокируется на время записи, трансляции, replay buffer, виртуальной камеры и обработки файлов. Проверить обновление вручную можно через меню «Справка». Обновление и восстановление через серверы исходного OBS отключены.
- Первый публичный переносимый ZIP для Windows x64, с лицензией, списком файлов установки и отдельной контрольной суммой.

## 0.0.1

Так обозначена предыдущая версия: панель проектов игр, конвертация MP4, доставка файлов и InfoWriter на LucidLink, прототип интеграции Premiere. Прежние ZIP с номером базы OBS `32.2.2` переименованы в `Polden-OBS-0.0.1-Windows-x64[-Personal].zip` без изменения их содержимого.
