# Основа и варианты README

Целевая аудитория — коллеги, которые уже снимают игровой материал и хотят готовить MP4 и доставлять футажи на LucidLink с меньшим количеством ручных действий. Входная точка — привычная запись OBS, затем выбор игры, режим после записи и маркеры.

## Из чего собран контекст

Прочитаны сообщения пользователя в чатах проекта «Добавить маркеры и сохранить имя», «Реализуй последние правки Polden OBS» и «Изучи ветку и реализуй правки», а также доступные части «Создай форк Polden OBS». Одна большая старая часть истории не открылась из-за ограничения размера инструмента. Контекст дополнен заметкой Polden OBS и проверен по текущему коду, документации и тестовой записи. Личная переписка и настройки в репозиторий не переносятся.

Подтверждённые приоритеты: исходные имена при конвертации и доставке; нативные цветные маркеры с горячими клавишами и необязательными кнопками; стандартный Full HD-пресет; настройка имени в Polden; отмена обработки; компактный интерфейс с понятным состоянием дубля. Интеграция Premiere удалена из этого приложения и не обещается в README.

## Иллюстрации

Снимки настоящего интерфейса Polden OBS 0.3.0 получены через computer-use в отдельной portable-конфигурации `tmp/readme-runtime`. Игра Demo Game и оператор Anna — учебные. Game Capture добавлен как отключённый источник; записана тестовая цветная сцена. LucidLink заменён локальной тестовой папкой. Рабочая игра, профили, сцены и папки пользователя не использовались.

`choose-mode.gif` показывает настоящие переключения трёх режимов; `record-mark-deliver.gif` — кадры настоящей записи с тремя маркерами и готовым результатом. Кадры собраны в GIF без изменения текста интерфейса. Схема `workflow.svg` нарисована отдельно и объясняет режим MP4 → Lucid. Макеты из старого ТЗ не выдаются за снимки приложения.

Проверены открытие изображений, кадры GIF и локальные ссылки. Исходные учебные записи, настройки, журналы и промежуточные кадры остаются в игнорируемом `tmp/`.
