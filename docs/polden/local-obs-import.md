# Перенос локального OBS

`scripts/import-local-obs.py` переносит активный профиль записи и InfoWriter из установленного OBS в портативную сборку Polden OBS. Перед запуском закройте Polden OBS. Исходный OBS можно оставить открытым: скрипт только читает его файлы.

```powershell
python scripts/import-local-obs.py --install-root 'T:\Programs\obs-studio'
```

Скрипт берёт активные профиль и коллекцию сцен из `%APPDATA%\obs-studio\user.ini`, копирует `basic.ini` и `recordEncoder.json` профиля, коллекцию сцен и `OBSInfoWriter.dll`. Коллекция нужна, поскольку настройки источника InfoWriter и его горячие клавиши хранятся внутри неё. Сервис потоковой трансляции (`service.json`) и его ключи не копируются. В Polden OBS меняется только выбор активного профиля и коллекции; существующие файлы при конфликте сохраняются с суффиксом `.before-obs-import`.

Персональный профиль, сцены и сторонний бинарный плагин находятся только в `build_x64/rundir/Release/`, который исключён из Git. При пересборке без удаления этого каталога они сохраняются. Для переносимого ZIP с ними запустите `python scripts/package-windows.py --include-local-settings`: он создаст отдельный архив `*-Personal.zip`. Храните его как личные данные и не публикуйте без проверки содержимого.

На этой машине источник — OBS Studio 32.0.1, плагин OBSInfoWriter 2.8.0; целевая сборка — Polden OBS 32.2.2. Пробный запуск 24.09.2026 показал `Startup complete`, загрузку `OBSInfoWriter.dll` и создание источника `Info Writer`. В логе есть предупреждение об отсутствующем тексте локализации `en-US`, которое встречается и в исходном OBS; оно не помешало загрузке плагина.
