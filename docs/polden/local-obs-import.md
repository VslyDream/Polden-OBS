# Перенос локального OBS

`scripts/import-local-obs.py` переносит активный профиль записи и сцены из установленного OBS в портативную сборку Polden OBS по ссылке `latest`. Перед запуском закройте Polden OBS. Исходный OBS можно оставить открытым: скрипт только читает его файлы. Начиная с 0.2.0 маркеры встроены в Polden и сторонняя DLL InfoWriter не копируется. Горячие клавиши цветов назначаются через **Polden settings… → Markers**.

```powershell
python scripts/import-local-obs.py --install-root 'T:\Programs\obs-studio'
```

Скрипт берёт активные профиль и коллекцию сцен из `%APPDATA%\obs-studio\user.ini`, копирует `basic.ini` и `recordEncoder.json` профиля и коллекцию сцен. Сервис потоковой трансляции (`service.json`) и его ключи не копируются. В Polden OBS меняется только выбор активного профиля и коллекции; существующие файлы при конфликте сохраняются с суффиксом `.before-obs-import`.

Персональный профиль и сцены находятся в каталоге сборки, на который указывает `latest`; он исключён из Git. При пересборке без удаления этого каталога они сохраняются. Для переносимого ZIP с ними запустите `python scripts/package-windows.py --include-local-settings`: он создаст отдельный архив `*-Personal.zip`, включая проекты Polden и назначения маркеров. Храните его как личные данные и не публикуйте без проверки содержимого.

Историческая проверка 24.09.2026: источник — OBS Studio 32.0.1 с OBSInfoWriter 2.8.0, целевая база Polden — 32.2.2. В 0.2.0 отдельный InfoWriter больше не загружается. [Формат встроенных маркеров](markers.md).
